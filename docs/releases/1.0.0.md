# Scribe Sync 1.0

Die erste Version der nativen Mac-App.

- Kindle-Scribe-Notizbücher werden automatisch über Amazon abgeholt, solange die App läuft. Der Mac wird nie dafür geweckt.
- Die Handschrift wird mit einer lokalen KI erkannt (Qwen 3.5 über Apple MLX). Das Modell ist nur während der Erkennung im Arbeitsspeicher.
- Text lässt sich korrigieren, mit Rechtschreibprüfung. Korrekturen bleiben erhalten, wenn eine Seite später ergänzt wird.
- Apple Notes: genau eine Notiz pro Notizbuch, die aktualisiert wird statt neu angelegt.
- Zeichnungen werden als Bildausschnitt der Seite eingebettet.
- Ein Diagnosefenster zeigt alle Hintergrundaktivitäten, den Speicherverbrauch und das Protokoll.
- Updates kommen automatisch über GitHub.
